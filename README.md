# 📊 HR Analyst Dashboard – Excel Project

## 📝 Project Overview
The **HR Analyst Dashboard** is an interactive Excel dashboard designed to analyze employee data and provide meaningful insights into workforce demographics, employee distribution, and HR performance.

This dashboard helps HR teams understand employee trends, monitor employee turnover, and analyze workforce information using KPIs, charts, and interactive filters.

## 🖼️ Dashboard Preview

![HR Analyst Dashboard](HR_Dashboard.png)

## 🎯 Key Performance Indicators (KPIs)

- **Total Employees:** 9,964
- **Leavers:** 1,290
- **Average Salary:** 81,364
- **Average Tenure:** 4.80 years
- **Average Age:** 43.39 years
- **Average Training Hours:** 49.05

## 📈 Dashboard Insights

The dashboard includes the following visualizations:

- **Gender Analysis:** Compares male and female employees.
- **Employee by Department:** Shows employee distribution across departments.
- **Work Mode Analysis:** Displays Contract, Full-Time, and Part-Time employees.
- **Employee by Year:** Section for analyzing hiring trends over time.
- **Top 5 Locations:** Highlights locations with the highest employee counts.
- **Bottom 5 Locations:** Identifies locations with lower employee counts.

## 🎛️ Interactive Filters

Users can filter the dashboard by:

- Gender
- Hire Date
- Department
- Location

These filters help explore employee data from different perspectives.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers and Date Timeline
- KPI Cards
- Data Visualization

## 💡 Key Objectives

- Analyze workforce demographics.
- Track employee turnover.
- Compare employee distribution by department.
- Understand location-wise workforce distribution.
- Monitor hiring trends and employee-related KPIs.
